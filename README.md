# Licitaciones_MP
Automatiza la búsqueda, filtrado y exportación de licitaciones públicas de Mercado Público (Chile), enfocadas en las palabras clave y criterios relevantes para nuestro equipo. El script consulta la API, aplica filtros (palabras clave, categorías, organismo comprador, fechas, etc.) y entrega un reporte estandarizado (Excel) para análisis rápido.
